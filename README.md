# 拾页 Folio｜本地文件与网络资料管理书柜

**给重要的文件，一个记得住的位置。**

“拾页”意为拾起散落的文件与文字，让重要资料有处可放、有迹可寻。

本地优先的书柜式文件与网络收藏管理器。把 Markdown、代码、文本、文学作品、PDF、图片和网络地址放进同一座书柜，找得到、读得舒服、整理得明白。

> **AI 使用声明：本项目由 OpenAI Codex 辅助设计、编写、测试和整理文档。** 具体范围见 [AI_USAGE.md](AI_USAGE.md)。

## 直接使用：Windows 免安装版

1. 在 [Releases](https://github.com/qianshan73/folio-bookshelf/releases/latest) 下载 `Folio-Windows-x64.zip`。
2. **完整解压**到一个可写入的文件夹，不要直接在压缩包里运行。
3. 双击 `start.cmd`，浏览器自动打开书柜。
4. 保持启动窗口打开，关掉它就会停止本地服务。再次启动，之前的收藏仍然在。

免安装包自带 Node.js 和运行依赖，无需账号、无需安装数据库，首次打开也不需要下载依赖。适用于 Windows 10/11 x64；原生文件选择窗口使用系统 PowerShell 和 Windows Forms。

**只在本机使用，不需要发布到公网。** GitHub 上只有项目源码、公开说明与原创示例；你的文件、路径、笔记和封面默认存放在本地 `data` 文件夹，不会提交到仓库或发送到云端。

## 能做什么

| 入柜方式 | 原文件怎么处理 | 适用场景 |
| --- | --- | --- |
| 上传 / 拖放文件 | 复制一份到本地书柜，原件不变 | 想长期保留一份独立内容 |
| 引用本地路径 | 不复制，读的是原文件 | 大文件、经常更新的代码与资料 |
| 导入文件夹 | 可选路径引用或复制，支持子文件夹 | 整理一批散落的文件 |
| 收藏网络链接 | 记录 HTTP(S) 地址和个人备注 | 文章、在线文档、网络作品 |
| 粘贴文字 | 自选 MD、TXT、JS、CPP 等或自定义文本扩展名 | 灵感、摘记、代码片段 |
| 导入 `.folio` 备份 | 合并已有书柜，不覆盖相同 ID | 迁移设备、恢复收藏 |

- **像书一样整理**：显示重命名、8 种封面色、自定义颜色、4 种纹理、上传自己的封面。
- **快速找回**：名称、标签、备注、路径和文本内容搜索；`Ctrl / ⌘ + K` 聚焦搜索。
- **前端整理**：拖动书籍调整顺序；拖到左侧分类即可归档；列表视图、类型筛选、多种排序。
- **真正移动原文件**：路径引用的「位置」页支持选择目标文件夹、更改文件名、确认移动、撤销；同名目标不会被覆盖。
- **阅读和编辑**：Markdown 安全渲染，代码语法高亮，文本预览，图片和浏览器内置 PDF 预览；文本副本可以直接编辑。
- **防遗忘**：特别珍藏、最近翻阅、回顾日期与到期列表。
- **检查原文件**：标出失联引用，重新定位文件，刷新内容索引。
- **恢复与备份**：回收站只移除记录；完整导出本地副本、封面、分类、标签与笔记。
- **舒适阅读**：浅色 / 深色主题、可调封面大小、移动端布局、键盘操作、减少动态效果支持。

## 第一次打开

书柜自带 7 份带「示例」标签的内容，包括入门说明、原创阅读札记和代码。它们只是项目示例，不是从你的电脑扫描到的文件。可自由修改或移入回收站。

点击右上角 **收进书柜**，选择想要的导入方式。要真正移动磁盘上的文件，请先用 **本地路径** 导入，打开书籍 → **位置**。书架拖放和左侧分类只调整书柜记录，不会移动磁盘文件。

更详细的操作说明在 [docs/使用指南.md](docs/使用指南.md)。

## 源码运行（Windows / macOS / Linux）

需要 **Node.js 24 或以上**，推荐当前 Node.js 24 LTS。开发版首次安装依赖需要联网，日常管理本地文件无需联网。打开外部收藏的网页仍需要网络。

```bash
git clone https://github.com/qianshan73/folio-bookshelf.git
cd folio-bookshelf
npm ci
npm start
```

浏览器访问 `http://127.0.0.1:4173`。Windows 也可以双击源码里的 `start.cmd`（已安装 Node.js 时会自动安装缺少的运行依赖）。macOS/Linux 可执行 `sh start.sh`，原生路径选择窗口仅 Windows 提供，其他平台手动填写绝对路径。

```bash
npm run dev       # 修改服务端后自动重启
npm test          # 后端集成测试
npm run test:ui   # 浏览器端到端测试，默认使用已安装的 Microsoft Edge
```

如果机器未安装 Edge，可执行 `npx playwright install chromium` 后设置 `PLAYWRIGHT_CHANNEL=chromium`。

### 自定义数据位置或端口

```powershell
# Windows PowerShell
$env:FOLIO_DATA_DIR = 'D:\我的书柜'
$env:PORT = '4174'
npm start
```

```bash
# macOS / Linux
FOLIO_DATA_DIR="$HOME/FolioData" PORT=4174 npm start
```

免安装包升级时，将旧版本 `data` 文件夹复制到新版本目录即可；复制前退出旧版本。路径引用原件不包含在 `data` 里，需要单独保存。

## 实现说明

- 前端：原生 HTML / CSS / ES Modules；无需前端构建即可启动。
- 服务端：Node.js 内置 HTTP 与文件系统 API。
- 数据库：Node.js `node:sqlite`，SQLite WAL，数据持久化在 `data/library.sqlite`。
- Markdown：Marked + DOMPurify；不执行导入内容中的脚本。
- 代码高亮：Highlight.js，在服务端生成，浏览器再次清洗 HTML。
- 文件移动：独占创建目标副本后删除源文件，可跨磁盘移动；确认后执行，不覆盖目标；数据库异常时尝试回滚移动。完整过程属于补偿式操作，不是文件系统与数据库之间的原子事务。
- 备份：版本化 JSON `.folio`，二进制文件以 Base64 保存，恢复时校验路径并合并记录。
- 本地访问：仅监听 `127.0.0.1`，检查 Host / Origin，变更操作要求会话令牌。
- 实验性 WebMCP：浏览器支持时注册只读书柜搜索工具，普通浏览器使用不受影响。

## 当前范围与边界

- 文件保存支持任何格式；文字预览支持 Markdown、TXT、常见代码等。PDF 与图片可预览；EPUB、DOCX 等格式目前下载后用对应软件阅读。
- 单文件副本上限 **32 MB**，封面图片上限 **5 MB**，单次本地文件夹导入上限 **1000 个文件**。大文件请用路径引用。
- 文本索引为每个文件前 **512 KiB**，预览为前 **2 MiB**；截断预览不会开放编辑。较大的文本全文可下载查看。
- 路径引用不跟踪系统外部移动。原件不在原处时会标为失联，需要重新定位。点击「检查文件」更新原件内容索引。
- 网络收藏只保存链接与个人笔记，**不是网页正文归档器**，不自动检查网页可用性；可用「粘贴文字」另存自己需要的内容。
- Markdown 外部图片默认不加载，避免阅读时自动访问第三方服务。
- 回顾日期在打开应用时展示，没有后台系统通知、邮件或定时自动任务。
- `.folio` 导出上限为 **256 MB 的文件原始总量**，导入请求上限 **128 MB**；大书柜直接在退出后复制整个 `data` 文件夹。备份只包含副本，路径引用只记录路径。
- 回收站不会物理删除保存的副本。替换过的封面文件也保留在数据目录中，方便找回。当前没有一键清空磁盘功能。
- 同一书柜推荐只启动一个服务进程。多窗口并发编辑暂按最后保存为准。
- Windows 原生选择窗口带明确的置顶所有者；等待选择时点击页面会重新置顶，取消或关闭后可再次打开。窗口打开、置顶、取消和重开已通过实际 GUI 测试。

## 项目结构

```text
folio-bookshelf/
├── public/              # 书柜界面、样式和交互
├── server.mjs           # API、本地文件操作、SQLite
├── start.cmd            # Windows 双击入口
├── launch.ps1           # 启动检查和浏览器打开
├── start.sh             # macOS / Linux 启动
├── scripts/             # Windows 便携版打包
├── test/                # API 与浏览器测试
├── docs/                # 使用指南、截图、验证记录
├── AI_USAGE.md          # AI 使用说明
└── data/                # 运行时数据，Git 忽略
```
