# 拾页使用指南

## 1. 把内容放进书柜

### 文件副本

点击「收进书柜」→「文件副本」，选择一个或多个文件，选择分类后确认。也可以把文件拖入整个书柜窗口：松开后会进入确认导入窗口，不会直接操作原文件。

书柜复制一份到自己的数据目录，原件保留原样。相同内容的副本默认跳过重复导入。若要保留相同文字的不同笔记，可用「粘贴文字」。

### 本地路径

点击「本地路径」，在 Windows 上点「选择文件」，也可粘贴绝对路径，每行一条。这里读的是原件，适合很大的文件和持续更新的资料。

浏览器本身不提供上传文件的完整磁盘路径，所以「文件副本」与「本地路径」是分开的两种明确操作。

### 文件夹

点「选择文件夹」或填写目录。选择「保留路径引用」或「保存独立副本」，再决定是否包含子文件夹。默认跳过隐藏条目、`node_modules`、`dist` 和名为 `data` 的目录，最多递归 12 层，不跟随符号链接。

### 网络链接

粘贴 HTTP(S) 地址，给它一个容易记住的名字，再留下你为什么收藏它。书柜只保留链接和个人备注；想离线留存文字，可以另外复制到「粘贴文字」。

### 粘贴文字

粘贴文字、代码或摘录，输入名称，再从「保存为文件类型」选择 MD、TXT、JS、CPP 等。也可以选择「自定义文本扩展名」，填写 lua、rst、ini 等扩展名。内容以 UTF-8 文本保存，可以继续预览、搜索和编辑；这不是二进制文档格式转换。

文件名称已经以所选扩展名结尾时，不会重复添加扩展名。

## 2. 让收藏更容易记住

打开任意书籍，切换到「档案」：

- 名称：书柜显示名称，不会更改磁盘原文件名。
- 分类：把内容安放到自己的分类。
- 标签：用中英文逗号分隔，例如「文学，常用，重要」。
- 备注：写下自己的记忆线索、推荐理由和用途。
- 回顾日期：日期到达后出现在「等你回顾」。

点「特别珍藏」，以后可以从左侧快速找到。读过的内容会自动进入「最近翻阅」。

## 3. 自定义封面

切换到「封面」选择颜色、纹理，或上传 PNG / JPEG / WebP 图片。文字封面使用书柜名称，改名后同步变化。封面操作即时保存。

## 4. 搜索与书架整理

- 输入文件名、标题、标签、备注、原路径或正文中的一句文字。
- 按 `Ctrl + K`（macOS 为 `⌘ + K`）快速定位搜索框。
- 可限制只看文字、代码、网络链接或其他文件。
- 拖动一本书到另一本书前，调整顺序，自动切回「书架顺序」。
- 拖到左侧分类，把它归档。手机上可通过「档案」选择分类，不依赖拖动。
- 分类旁的「+」创建自己的分类。

**上述操作不会移动磁盘原文件。**

## 5. 实际移动磁盘上的文件

此功能仅对「路径引用」开放，副本可通过「下载 / 另存」复制到其他位置。

1. 打开书籍 →「位置」。
2. 选择目标文件夹，必要时更改目标文件名（请保留正确扩展名）。
3. 点「移动原文件」，核对原地址与目标地址。
4. 确认后移动原件并更新引用；已有同名文件会阻止操作，不会覆盖。
5. 可点击成功消息里的「撤销」，或「位置」里的「撤销上次移动」。

跨磁盘时使用先复制再删除的方式；若源文件正在被其他软件占用，操作会报告失败。撤销回原位置时，如已有同名文件，同样会停止。

## 6. 原文件失联怎么办

「需要重新定位」列出已经不在原处的本地文件。

打开书籍 →「位置」→「重新定位」，选择现存的原文件，然后「更新引用位置」。书柜分类、名称、封面和备注保留，引用和内容索引更新。

如果原文件内容发生变化，顶部「检查文件」会更新路径引用的文本索引；单本书也可点「刷新内容索引」。阅读时直接读取现存原件。

## 7. 备份与升级

「偏好与备份」→「导出备份」，下载 `.folio` 文件。

- 包括：书柜记录、分类、文件副本、封面、标签、备注和回顾日期。
- 不包括：路径引用的外部原文件，仅保存原路径。
- 导入时按收藏 ID 合并，同一份收藏不会重复恢复；不会覆盖已有收藏。
- 换设备后，路径引用通常需要重新定位。

大书柜请关闭启动窗口后，复制整个 `data` 文件夹。恢复时也先退出应用。升级便携版时把旧版 `data` 文件夹复制到新版目录，避免把仅含路径引用的备份当成原件备份。

## 8. 常见问题

**关闭浏览器是不是退出？** 浏览器关闭后，本地服务仍在。关闭启动窗口才会停止服务。

**能从手机管理电脑原文件吗？** 移动布局可用，但服务默认只在本机监听；没有开放局域网访问或远程管理。

**能修改导入的外部代码文件吗？** 原文件预览是只读的。书柜副本中的文本可编辑，外部文件用原来的编辑器修改。

**删掉收藏会不会删掉文件？** 不会，移入回收站只改变记录。副本仍留在数据目录，也可恢复。

**打不开启动脚本？** 先完整解压便携包，确认目录可写。源码包需要 Node.js 24+，便携包不需要单独安装 Node.js。

**端口 4173 被其他程序占用了？** 使用源码启动并设置 `PORT=4174`，然后访问对应地址；程序会保留数据，不更改占用端口的其他程序。

**需要账户或付费 API 吗？** 不需要。项目运行没有 AI API 调用，文件与书柜记录保存在本地。
