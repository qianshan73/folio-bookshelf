# 发布验证记录

日期：2026-10-02（Asia/Shanghai）

## 执行环境

- Windows x64。
- Node.js 25.9.0 开发环境与发布包的 Node.js 24.21.0 LTS 均执行通过全部后端测试。
- 使用本机 Microsoft Edge 运行 Playwright 自动化。
- 所有测试使用临时目录和项目原创示例，不读取或发布用户个人文件。

## 后端：10 组集成测试通过

`npm test`

1. 健康检查、前端资源、本地 Origin / Token 校验。
2. 文件副本导入、SHA-256 重复检测、中文内容搜索、LIKE 通配符转义。
3. 显示改名、标签、分类、珍藏、回顾日期、封面上传与内容编辑。
4. HTTP(S) 链接限定与原始文本下载行为。
5. 本地引用、读取、确认移动、不覆盖、跨目录移动和多次撤销。
6. 失联检测、重新定位与内容索引更新。
7. 递归文件夹导入和忽略目录规则。
8. 排序、回收站和原文件保留。
9. 完整备份、异库恢复、幂等合并、路径穿越与标签格式校验。
10. 服务完全重启后数据保留。

## 前端：端到端流程通过

`npm run test:ui`

- 书柜加载、中文正文搜索、Markdown 阅读。
- 名称、标签、回顾日期保存。
- 自定义颜色与纹理保存。
- 副本内容编辑、创建笔记。
- 浏览器上传 Markdown 文件、正文检索、收藏网络链接、导出备份与合并恢复。
- Ctrl + K 搜索快捷键。
- 列表 / 书柜视图切换。
- 回收站移入和恢复。
- 拖动调整顺序、拖到分类归档。
- 前端确认实际移动临时文件、撤销移动，检查磁盘结果。
- 深色主题。
- 390px 移动视图无横向页面溢出，设置窗口可打开。
- 浏览器没有未处理 JavaScript 异常。
- Windows PowerShell 启动脚本实际启动本地服务，验证版本检查、端口设置和入口响应。
