- Node.js 25.9.0 开发环境与发布包的 Node.js 24.21.0 LTS 均执行通过全部后端测试。

## 后端：10 组集成测试通过

`npm test`

1. 健康检查、前端资源、本地 Origin / Token 校验。
2. 文件副本导入、SHA-256 重复检测、中文内容搜索、LIKE 通配符转义。
3. 显示改名、标签、分类、珍藏、回顾日期、封面上传与内容编辑。
4. HTTP(S) 链接限定与原始文本下载行为。
5. 本地引用、读取、确认移动、不覆盖、跨目录移动和多次撤销。
6. 失联检测、重新定位与内容索引更新。
7. 递归文件夹导入和忽略目录规则。
8. 排序、回收站和原文件保留。
9. 完整备份、异库恢复、幂等合并、路径穿越与标签格式校验。
10. 服务完全重启后数据保留。

## v1.1.0 独立阅读与原文件归拢验证

- 默认自动化测试：18 项通过，2 项真实桌面选择窗口测试默认跳过。
- 独立运行真实 Windows 选择窗口测试：6 项通过（包含文件与文件夹选择窗口的置顶、重新置顶、取消和重开）。
